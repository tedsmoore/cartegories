# Product Overview

## What Is Cartegories?

A category card game for the car. Players draw cards with category prompts and try
to name items in the category before time runs out.

## Game Mechanics (Summary)

- Players select which decks to play with
- A timer counts down while players draw category cards
- Each card is marked "nailed" or "missed"
- Game ends when the timer hits zero
- Score breakdown shows results
